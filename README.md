# solar-fast-handheld

[![License: PolyForm Noncommercial 1.0.0](https://img.shields.io/badge/License-PolyForm_NC_1.0.0-lightgrey.svg)](https://polyformproject.org/licenses/noncommercial/1.0.0)
[![Source Available](https://img.shields.io/badge/Source-Available-blue.svg)]()

`solar-fast-handheld` 是 `solar-fast` 计算引擎的掌上终端与 UI 层。

面向 1.8" ST7735S 彩色液晶屏（原生 128×160 竖屏，本 UI 按 **160×128 横屏**使用），
包含 UI 渲染、按键状态机、汉字字模库，以及 macOS Cocoa 桌面模拟器。

---

## 页面与功能

1. **主页（日月万年历）**：
   * 瞬时公历、农历、月相盘动态朝向与受光率、日出日落时刻。
2. **太阳与黄道坐标页**：
   * 实时视赤经、视赤纬、日地距离、视高度角、均时差、真恒星时。
3. **二十四节气年表页**：
   * 当前公历年全部 24 节气精确交节时刻（精确定气求解）。
4. **合朔望月年表页**：
   * 全年朔（新月）、望（满月）、两弦时刻表。
5. **八字排盘与神煞页**：
   * 瞬时或指定生辰四柱、藏干、十神、纳音、神煞格局。
6. **大运与流运限页**：
   * 精确起运时刻、十步大运、流年、流月、流日推算。
7. **梅花与六爻**：
   * 两个独立入口、各自保存占时；默认跟随现在，也可用公历或农历手动指定。
     梅花先选农历时间、报数或设置占时；报数再选单数（配所选占时的时辰）或双数。
     三种结果都紧凑绘制本、变、互、错、综五卦的六爻图、卦名与体用关系。
   * 六爻可按初爻到上爻手动输入 6/7/8/9；排盘将本卦与变卦的爻象、纳支、
     六亲并排显示，内外卦纳干列在列头，世应按爻标记；左侧灰字为按占时日干起的六神，
     顶栏列完整年、月、日、时四柱（月柱按节气定），本卦名后标八宫层次；
     两卦之间以 ○ 标老阳、× 标老阴。
     动爻的爻画用橙色，地支正常保持深色；命中当天旬空两支的地支变灰，
     纳干行同时列出“空××”。
     伏神取本卦缺失六亲在本宫纯卦的同位爻，以彩色三字“六亲＋干支”显示在本卦行末。
     “神煞”页目前显示驿马、空亡、桃花、贵人。
   * 起卦规则来自同一作者的 `taiyin-lite/packages/liuyao`（`liuyao-lite`），
     八宫纳甲与世应另按京房规则实现；固件不带《周易》经文、《易传》或断卦文字。
   * 功能选择主页的“清空卦象”需二次确认；只清梅花、六爻的占时、报数、爻象与起卦动画状态，
     不重启设备，不改变当前时间、历法设置或八字出生信息。

## 依赖关系

本终端应用依赖 `solar-fast` 核心计算库。

* 克隆本仓库到与 `solar-fast` 相同的父级目录下：
  ```bash
  Developer/
  ├── solar-fast/           # 天文/历法核心计算库 (MPL-2.0)
  └── solar-fast-handheld/  # 掌上终端与 UI 系统 (PolyForm NC 1.0.0)
  ```
* 亦可通过 Git Submodule 引入。

## 编译与运行桌面模拟器

### macOS (Cocoa 原生零依赖)
```bash
make
./sim
```

### SDL2 后端（尚未提供）

`host_sdl.c` 未随本仓库发布，`make BACKEND=sdl` 会显式报错。
当前可用的宿主后端只有 macOS Cocoa。

### ESP32-S3 实机固件

`firmware/` 是 ESP-IDF 5.5 工程，默认将同一套便携 UI 与 `solar-fast` 核心编进
ESP32-S3 固件，使用 160×128 横屏 ST7735S 和 K1–K8 八个独立按键。接线、
编译刷机、自检模式和串口校时方法见 [firmware/README.md](firmware/README.md)。

开发板没有断电保持的时钟；不接网络或外部 RTC 时，断电重启后需要通过串口重新
校时。这个限制只影响“现在”对应的日期与时刻，不影响手动选定年份的历算算法。

### 模拟器按键操作

**面板按键 K1–K8**（数字键 `1`–`8` 与别名键完全等价）：

| 按钮 | 别名键 | 功能 |
|---|---|---|
| K1 | `W` / `↑` | 上 |
| K2 | `S` / `↓` | 下 |
| K3 | `A` / `←` | 左 |
| K4 | `D` / `→` | 右 |
| K5 | `Space` / `Return` | 确认 |
| K6 | `Esc` / `Delete` | 返回 |
| K7 | `Tab` / `M` | 菜单 |
| K8 | `Z` | 动作 |

**宿主专用键**（不属于那 8 个按钮）：

| 键 | 功能 |
|---|---|
| `[` / `]` | 时间 −1 / +1 天（按住可自动重复） |
| `\` | 复位时间 |
| `-` / `=` 或 `+` | 缩放 −1 / +1 |

**页面级覆盖**：二十四节气页与合朔望月页把 K5/K7/K8 重载为「编辑年份」三键
（K5 不再是「回主页」，K8 不再是「日夜主题」），方向键与翻页键不受影响。
K7 依次切换 1、10、100、1000 年和「回今」；选中「回今」后按 K5，会按历法日界
回到当前年，并将列表定位在当前节气或下一次朔望附近。八字出生年份也可用
K7 选 1、10、100、1000 年档，K5 按 K8 指定的方向调节。

梅花与六爻在功能选择页分开。梅花先用 K1/K2 选“农历时间”“报数”或“设置占时”，K5 进入；
报数再选“单数”或“双数”。单数配所选占时的历法时辰，双数分别输入上数、下数；
报数页 K1/K2 选数（单数只有一项）、K7 选 1/10 步长、K8 切增减、K5 调数，
K6 逐层返回。六爻页 K3/K4 在排盘、“神煞”“占时”间切换，K1/K2 选爻（从初爻到上爻）、
K8 切增减、K5 在老阴 6／少阳 7／少阴 8／老阳 9 间切换。
占时编辑页 K1/K2 上下选字段，K5 切换公历／农历或调值，K7 切换 1/10 步长，K8 切增减；
改过日期或时间后按 K6 直接保存返回（底部会显示“K6保存”）；没改过时 K6 只返回，
不会把当前时刻意外冻结。选“跟随现在”按 K5 则恢复实时占时。
梅花顶栏显示所选占时的农历年月日时辰；六爻顶栏四柱、六神及神煞／空亡都依六爻占时重算。
想清掉演示时的卦，不必重启校时：退回功能选择主页，选第五项“清空卦象”，
再按一次 K5 确认；K6 可取消。完成页按 K5 或 K6 返回。
六爻页第一次按 K7 只进入三钱起卦待摇画面；再按 K7 才开始摇初爻。此后每爻按两次 K7（摇币、停币），从初爻向上累积。
停币后三枚钱翻落，正面显示 `+`、反面显示 `−`，随后左侧由左向右显爻；
右边三枚钱在下次起摇时升到下一爻。落币期间再按 K7 可跳过过渡，不会重复取随机数。
六爻完成后按 K5，纳甲盘从初爻向上逐行接替起卦画面；K7 可重摇。
未完成时 K6 或翻页会取消并恢复原卦。停币时从宿主随机源抽取三枚钱：
ESP32 固件调用 `esp_random()`，起卦期间临时启用内部 SAR ADC 熵源；
Mac sim 调用系统 `arc4random()`。编译目标决定实现，
不使用时间种子。当前设备没有同时使用 ADC 或 RF；以后接入这些外设时须重新检查
熵源启停的互斥条件。
