# ESP32-S3 固件

默认构建完整的 `solar-fast-handheld` UI 与 `solar-fast` 计算核心。屏幕和按键自检
可用 `-DHANDHELD_HWTEST=ON` 单独构建。

```sh
idf.py -B build-app -DSDKCONFIG=build-app/sdkconfig -p /dev/cu.usbserial-XXXX flash monitor
```

先进入已安装的 ESP-IDF 5.5 环境，并将示例串口名替换成自己设备的端口。

屏幕信号：`SCK→GPIO12`、`SDA(MOSI)→GPIO11`、`CS→GPIO10`、`A0/DC→GPIO9`、`RESET→GPIO8`。按键：`K1..K8→GPIO4,5,6,13,14,15,16,17`。两块模块都接 GND，按键 VCC 接 3V3。屏幕 VCC 和 LED 都应接 3V3。

这款双 USB-C ESP32-S3 板的 `5Vin` 默认是输入脚；`IN-OUT` 焊桥未接通时，USB 供电不会从该脚输出。不要把屏幕 VCC 接到未验证的 `5Vin`。要同时连接屏幕 VCC、LED 和按键 VCC，需安全地把一个 3V3 端分成两路（例如一分二杜邦线）。

完整 UI 的 K1..K8 依次是上、下、左、右、确定、返回、菜单、动作。K8 在普通页面切换日夜主题，在编辑页面可能另有用途。
功能选择页现有万年历、八字、梅花、六爻四项，末尾另有“清空卦象”。
选清空后再按 K5 确认、K6 取消；它只复位梅花与六爻的易失起卦状态，
不重启、不影响设备时间、历法设置或八字出生信息。
梅花先选农历时间、报数或设置占时，
报数再选单数（配所选占时的时辰）或双数；三种结果都显示本、变、互、错、综五卦的爻图。
报数页 K7 选步长、K8 切增减、K5 调数，K6 逐层返回。
六爻页 K3/K4 在排盘、“神煞”“占时”间切换；K1/K2 选爻、K5 改爻值。
梅花、六爻各自保存占时，默认跟随现在；占时页可在公历／农历输入间切换。
K1/K2 选字段，K5 调值或确认，K7 切 1/10 步长，K8 切增减；
改过时间后 K6 保存返回（底部有“K6保存”提示），未改时 K6 只返回；
“跟随现在”恢复实时占时。六爻四柱、六神、神煞与空亡均按所选占时重算。
K7 先进入三钱起卦待摇画面；再按 K7 才摇初爻。此后每爻按两次（摇、停），从初爻往上显示在左侧，
三枚钱在右侧跟随当前爻；停币后翻落，正面 `+`、反面 `−`，落稳后左侧显爻。
落币期间 K7 可跳过动画而不重复取随机数。六爻完成后按 K5，
纳甲盘从初爻向上逐行接替起卦画面；K7 重摇，
中途 K6 或翻页取消并恢复原卦。
六爻页并排显示本卦与变卦的六亲、地支和爻象，内外卦纳干只在列头显示。
本卦最左侧灰字为按占时日干起的六神（龙、雀、勾、蛇、虎、玄），六亲与纳支用深色。
顶栏显示年、月、日、时四柱（月柱按节气定）；本卦名后括号标出八宫和世次。
两卦之间用 ○ 表示老阳（9）、× 表示老阴（6），静爻不标。
动爻爻画用橙色，地支不跟随动爻变色；日柱旬空的地支变灰，纳干行列出空亡两支。
世应标在本卦爻旁；伏神在本卦行末以彩色“六亲＋干支”三字表示。
停币时调用三次 `esp_random()`，
并在抽样期间临时启用内部 SAR ADC 熵源，抽完即关闭；“神煞”页目前显示驿马、空亡、桃花、贵人。

此板没有断电保持的时钟。固件启动时暂用镜像的构建时间；接着可从电脑串口发送
`T<Unix UTC 秒>\n` 校时。例如：

```sh
python3 sync_time.py /dev/cu.usbserial-XXXX
```

`sync_time.py` 需要 `pyserial`（`python3 -m pip install pyserial`）。

断电重启后需重新校时，或以后接入网络校时/独立 RTC。

自检版构建：

```sh
idf.py -B build-hwtest -DSDKCONFIG=build-hwtest/sdkconfig -DHANDHELD_HWTEST=ON \
  -p /dev/cu.usbserial-XXXX flash monitor
```

自检画面上方是八条彩带，下方八个灰块分别对应 K1..K8；按键按下时相应灰块变绿。串口输出 `pressed mask`，K1 对应 `0x01`，K8 对应 `0x80`。
